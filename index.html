Our path to an AI trading system

No paid API is required to begin. Your risk limits are now configurable; realistic options backtesting and automation come after we can obtain suitable data.

01
Collect clean historical data

Import complete 5-minute SPY sessions. Later add historical option-chain quotes and fills.

02
Test deterministic rules

Backtest ORB, PDH/PDL reclaims, VWAP retests, and time-of-day filters without lookahead bias.

03
Prove an edge out of sample

Use separate training, validation, and walk-forward test periods with conservative assumptions. Compare to a simple non-AI baseline.

04
Add an AI ranking layer

Train models to rank setups on features known at entry, then measure whether the AI genuinely improves expectancy and drawdowns.

05
Paper trade live with safeguards

Connect a supported real-time data feed. Enforce position limits, one-loss lockout, order checks, and a kill switch.

06
Consider controlled live deployment

Only after substantial forward testing, technical audits, and strict account-level limits. No profits are guaranteed.

How your phone version works

This is a single HTML file with embedded code. It requires no server, account, Python installation, subscription, or internet connection after opening. Use the Risk setup tab to change your stop, size, maximum premium, and OTM distance.

No brokerage login, API token, or order placement is built in. CSV files stay in memory while this page is open. Journal entries and strategy settings use local browser storage where supported; clearing website data may erase them. Export your journal for a backup.

For an app icon and dependable iPhone Safari access, this file can later be deployed as a secure HTTPS website and installed to the Home Screen. That also gives us a place to add protected server-side services, without storing brokerage secrets in phone-browser code.
